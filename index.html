For this project I wanted to be able to try my hand at some of the web-scraping tools that I had just learned about a few days prior, then apply some data analysis and some machine learning on the data I obtain. I decided that I would be using the tools to gather data about real estate listings across Canada. The listings that I will be scraping for contain various variables that I will store, along with some variables I stored myself:
  • Province and City (I choose them myself, to determine what pages are scraped)
  • Listed Price (in $CAD)
  • Number of bedrooms (stored as an integer)
  • Number of bathrooms (stored as an integer)
  • Square footage (stored either as a range, or a single integer)
  • Property type (a string denoting what category it falls under)
    • One of: House, Apt/Condo, Townhouse, Duplex, Mfd/Mobile Home, Multifamily, Fourplex, Land/Lot, Triplex, Recreational
Step 1: Importing Helpful Libraries
Before I start writing any code, I need to consider the different Python libraries and tools that I may require to complete this project. First of all I will need a tool that can scrape webpages for their HTML information, and since this is a big project, I would also like a tool to open new webpages automatically in separate tabs. Finally, I will need somewhere to store and clean all of this data for later analysis. The following libraries and tools should fix all of these problems respectively:
  • BeautifulSoup: A tool for scraping HTML from webpages, returning any section I specify
  • Selenium Webdriver: A tool that can open, close, and navigate webpages quickly and efficiently
  • re (Regex): Expressions used to find certain patterns in text that I define
  • Pandas: A database tool that can store, manipulate, and export any data that I obtain

    Step 2.2: Writing Regex Patterns
    Next I have to set up the Regex patterns that I will be looking for within the HTML strings that I scrape. Since the string has lots of unimportant characters, I need to create a unique pattern for each piece of information that I want to look for. To determine these patterns, I scraped a single webpage to find the default structure of the HTML strings that I would be obtaining. Within that string, I manually found each piece of information and then created a pattern that would only match that exact piece of information. This could raise problems if the website had wildly inconsistent HTML structure, fortunately this was not an issue. Here's what I came up with:

# pattern for price
pricePat = r'\$[0-9,]+<'
# pattern for bedrooms
bedPat = r'>[0-9 \+]+ bd</li'
# pattern for bathrooms
bathPat = r'>[0-9 \+]+ ba</li'
# pattern for square feet
sqftPat = r'[0-9][0-9 -]+ sf</li'
# pattern for property type
ptPat = r'(?!.*wrap">).*?</div></section>'
      Step 2.3: Creating Helper Functions
      Before moving on to the scraping function, there's one last thing to do: write some helper functions! Even after scraping the webpage for HTML and matching regex patterns to get the correct pieces of information, there is still some tweaking that needs to be done to make sure the data is consistent and formatted. Price is written as a string with commas to separate thousands, but since I want to store it as a number I will need a function to fix this. Bedroom and bathroom numbers can sometimes be written in the format "x+y" where "x" represents main bedrooms/bathrooms and "y" represents partial ones. It would make it a lot easier to simply add these values together to make sure bedroom and bathroom counts are consistently represented as a single integer. Finally the square footage can sometimes be written as a range, and other times as just one value (the maximum). To keep consistent, any range is simply turned into its max value. Here are the functions I created to solve these problems:

        ## Helpful function for turning price strings into integers
def priceRead(prc):
    prc = prc.replace(',', '')
    return int(prc)

## Helpful function for turning bed/bath strings into integers
def bedRead(bd):
    if '+' in bd:
        # remove spaces
        bd = bd.replace(' ', '')
        # return sum of numbers
        bd = bd.split('+')
        return int(bd[0]) + int(bd[1])
    else:
        return int(bd)

## Helpful function for turning sqft strings into values
def sqftRead(sq):
    if '-' in sq:
        # remove spaces
        sq = sq.replace(' ', '')
        # return max of numbers
        sq = sq.split('-')
        return int(sq[1])
    else:
        return int(sq)
        Step 3: Writing the Scraping Function
        Now that all of the setup has been finished, I can finally begin writing the scraping function. I want to create a function that takes as input the location lists I defined in step 2.1, and outputs a whole data list containing the information I'm scraping for. Thankfully all of this preparation should make writing this function much easier. Let's go through the steps that this function executes in order:
        1. Before looping through any pages I create the webdriver dr in Chrome, define a base URL string baseURL, and initialize the list houses which will contain the data. I also define a variable prevLen which will help to know when I've reached the end of a page.
        2. Now I take the city name city from the list and begin at the first page pageNum = 1 of the site.
        3. I create the new URL url that I will scrape using the baseURL, city, and pageNum
        4. I use the webdriver dr to access the URL, then Beautiful Soup soup is used parse the HTML and find the chunk that contains the information I need to be stored in houseList. I also check in case I've gone past the last page of listings for the city, in which case I move on to step 8.
        5. I take a house string in the houseList and using the helper functions and regex patterns I created prior, I collect and organize all of the information into a data object and add it to the houses list. I repeat this step until I've gone through the entire houseList.
        6. Due to possible errors or website blocking, I have to check if the current page correctly added new information to the houses list. If it did, we move on. If it failed, we repeat from step 3 to re-scrape the page.
        7. The page was scraped successfully so I increment the pageNum and return to step 3.
        8. Every page of the city's listings was scraped correctly so I move on to the next city in the list and return to step 2. If there are no more cities, the function is complete and I return the houses list of data I collected.
        In [5]:
        def CityListScraper(cityList):
    """Scrape website for house listing data
    Input: list object in form ['Province', 'city1-pr', 'city2-pr', ...]
    Output: list of house listings containing price, size, beds, baths, and property type
    """
    dr = webdriver.Chrome()
    baseURL = 'https://www.rew.ca/properties/areas/'
    prevLen = 0
    houses = []
    
    for city in cityList[1:]:
        print("Scraping", city, "...")
        pageNum = 1
        while (True):
            # get new URL
            url = baseURL + city + '/page/' + str(pageNum)
            
            # and scrape it to turn it into a helpful list
            dr.get(url)
            soup = BeautifulSoup(dr.page_source, "html.parser")
            houseList = soup.find_all('div', {'class':'displaycard-body'})
            
            # check if we have gone past last page
            if soup.find('div', {'class':'pageblock-cta_wrapper'}):
                break
        
            # go through each house in the list
            for index, house in enumerate(houseList):
                house = str(house)
                price = re.search(pricePat, house)
                if price:
                    price = priceRead(price.group()[1:-1])
                bed = re.search(bedPat, house)
                if bed:
                    bed = bedRead(bed.group()[1:-7])
                bath = re.search(bathPat, house)
                if bath:
                    bath = bedRead(bath.group()[1:-7])
                sqft = re.search(sqftPat, house)
                if sqft:
                    sqft = sqftRead(sqft.group()[0:-7])
                prop = re.search(ptPat, house)
                if prop:
                    prop = prop.group()[5:-16]
                data = {
                    "Province": cityList[0],
                    "City": city,
                    "Price": price,
                    "Bedrooms": bed,
                    "Bathrooms": bath,
                    "Square Feet": sqft,
                    "Property Type": prop
                }
                houses.append(data)
            
            # only proceed to next page if current page was properly scraped
            if len(houses) > prevLen:
                print("      Scraped page", pageNum, "| total listings:", len(houses))
                #print(houses)
                pageNum += 1
                prevLen = len(houses)
        

    # After everything, return the list
    return houses
