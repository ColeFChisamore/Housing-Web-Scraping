    Step 2.2: Writing Regex Patterns
    Next I have to set up the Regex patterns that I will be looking for within the HTML strings that I scrape. Since the string has lots of unimportant characters, I need to create a unique pattern for each piece of information that I want to look for. To determine these patterns, I scraped a single webpage to find the default structure of the HTML strings that I would be obtaining. Within that string, I manually found each piece of information and then created a pattern that would only match that exact piece of information. This could raise problems if the website had wildly inconsistent HTML structure, fortunately this was not an issue. Here's what I came up with:

# pattern for square feet
sqftPat = r'[0-9][0-9 -]+ sf</li'
# pattern for property type
ptPat = r'(?!.*wrap">).*?</div></section>'
      Step 2.3: Creating Helper Functions
      Before moving on to the scraping function, there's one last thing to do: write some helper functions! Even after scraping the webpage for HTML and matching regex patterns to get the correct pieces of information, there is still some tweaking that needs to be done to make sure the data is consistent and formatted. Price is written as a string with commas to separate thousands, but since I want to store it as a number I will need a function to fix this. Bedroom and bathroom numbers can sometimes be written in the format "x+y" where "x" represents main bedrooms/bathrooms and "y" represents partial ones. It would make it a lot easier to simply add these values together to make sure bedroom and bathroom counts are consistently represented as a single integer. Finally the square footage can sometimes be written as a range, and other times as just one value (the maximum). To keep consistent, any range is simply turned into its max value. Here are the functions I created to solve these problems:

        ## Helpful function for turning price strings into integers
def priceRead(prc):
    prc = prc.replace(',', '')
    return int(prc)

## Helpful function for turning bed/bath strings into integers
def bedRead(bd):
    if '+' in bd:
        # remove spaces
        bd = bd.replace(' ', '')
        # return sum of numbers
        bd = bd.split('+')
        return int(bd[0]) + int(bd[1])
    else:
        return int(bd)

## Helpful function for turning sqft strings into values
def sqftRead(sq):
    if '-' in sq:
        # remove spaces
        sq = sq.replace(' ', '')
        # return max of numbers
        sq = sq.split('-')
        return int(sq[1])
    else:
        return int(sq)

houses = []

def CityListScraper(cityList):
    dr = webdriver.Chrome()
    baseURL = 'https://www.rew.ca/properties/areas/'
    prevLen = 0
    houses = []
    
    for city in cityList[1:]:
        print("Scraping", city, "...")
        pageNum = 1
        while (True):
            # get new URL
            url = baseURL + city + '/page/' + str(pageNum)
            
            # and scrape it to turn it into a helpful list
            dr.get(url)
            soup = BeautifulSoup(dr.page_source, "html.parser")
            houseList = soup.find_all('div', {'class':'displaycard-body'})
            
            # check if we have gone past last page
            if soup.find('div', {'class':'pageblock-cta_wrapper'}):
                break
        
            # go through each house in the list
            for index, house in enumerate(houseList):
                house = str(house)
                price = re.search(pricePat, house)
                if price:
                    price = priceRead(price.group()[1:-1])
                bed = re.search(bedPat, house)
                if bed:
                    bed = bedRead(bed.group()[1:-7])
                bath = re.search(bathPat, house)
                if bath:
                    bath = bedRead(bath.group()[1:-7])
                sqft = re.search(sqftPat, house)
                if sqft:
                    sqft = sqftRead(sqft.group()[0:-7])
                prop = re.search(ptPat, house)
                if prop:
                    prop = prop.group()[5:-16]
                data = {
                    "Province": cityList[0],
                    "City": city,
                    "Price": price,
                    "Bedrooms": bed,
                    "Bathrooms": bath,
                    "Square Feet": sqft,
                    "Property Type": prop
                }
                if sqft == 0:
                    print(house,'\n')
                houses.append(data)
            
            # only proceed to next page if current page was properly scraped
            if len(houses) > prevLen:
                print("      Scraped page", pageNum, "| total listings:", len(houses))
                #print(houses)
                pageNum += 1
                prevLen = len(houses)
        

    # After everything, return the list
    return houses
